# 数字と単位の読み方

[用語集の入口](README.md) / [さくいん](index.md) / [前: 構築プロジェクトと現場の言葉](13-project.md) / [次: 混同しやすい言葉の対比表](compare.md)

サーバーの会話は、ほとんどが数字で進みます。単位が読めるようになると、障害の報告も設計の相談も一気に楽になります。ここに出てくる目安の数字は、すべて概算です。

## 表 1: 大きさの単位

| 単位 | 読み | 意味 | 身近な目安 |
| --- | --- | --- | --- |
| bit（b） | ビット | 0 か 1 のどちらかを表す、いちばん小さい単位です | 情報の最小のかたまりです |
| byte（B） | バイト | bit を 8 個まとめた単位です | 半角の英数字 1 文字ぶんです |
| KB | キロバイト | 約 1,000 byte です | 短い文章のファイル 1 つぶんです |
| MB | メガバイト | 約 1,000 KB です | 写真 1 枚が数 MB になることが多いです |
| GB | ギガバイト | 約 1,000 MB です | メモリ容量の話でよく出てくる単位です |
| TB | テラバイト | 約 1,000 GB です | ディスク 1 台の容量でよく見かける規模です |
| PB | ペタバイト | 約 1,000 TB です | 大規模なデータ基盤で出てくる規模です |

KB と KiB は別物です。1 KB は 1,000 byte、1 KiB は 1,024 byte を指します。そのため、同じファイルでもツールによって表示される数字が少しずれます。MB と MiB、GB と GiB も同じ関係です。

## 表 2: 速さと時間の単位

| 単位 | 読み | 意味 | これが悪いとどうなるか |
| --- | --- | --- | --- |
| bps | ビーピーエス | 1 秒間に送れる bit の数です | 小さいと通信そのものに時間がかかります |
| Mbps | メガビーピーエス | 1 Mbps は約 100 万 bps です | 小さいとダウンロードや画面表示が遅くなります |
| Gbps | ギガビーピーエス | 1 Gbps は約 1,000 Mbps です | 小さいとサーバー間の大きな転送が詰まります |
| ms | ミリ秒 | 1,000 分の 1 秒です | 大きいと利用者が「重い」と感じます |
| μs | マイクロ秒 | 100 万分の 1 秒で、1 ms の 1,000 分の 1 です | 大きいと積み重なって全体の応答が遅くなります |
| RPS | アールピーエス（リクエスト毎秒） | 1 秒間に処理するリクエストの数です | さばける上限を超えると、待ち時間が増えエラーも出ます |
| IOPS | アイオップス | 1 秒間にできるディスクの読み書き回数です | 上限に近づくとデータベースの応答が遅くなります |
| Hz / GHz | ヘルツ / ギガヘルツ | 1 秒間に刻む回数で、1 GHz は約 10 億 Hz です | 低いと 1 件ずつの処理に時間がかかりやすくなります |

リクエストとは、利用者やほかのプログラムからサーバーに届く 1 件の依頼のことです。なお、GHz の数字が大きいほど必ず速い、とは限りません。CPU の世代や種類によっても性能は変わります。どの値なら十分かは、扱うサービスや構成によって異なります。まずは「前より良くなったか悪くなったか」を見る物差しとして使ってください。

## 表 3: 割合の読み方

| 表記 | 読み | 意味するところ |
| --- | --- | --- |
| 99% | きゅうじゅうきゅうパーセント | 稼働率の目安です。年間の停止時間は概算で 3.6 日ほどです |
| 99.9% | スリーナイン | 稼働率の目安です。年間の停止時間は概算で 8.8 時間ほどです |
| 99.99% | フォーナイン | 稼働率の目安です。年間の停止時間は概算で 53 分ほどです |
| CPU 使用率 | シーピーユーしようりつ | CPU がどれだけ働いているかの割合です |
| ディスク使用率 | ディスクしようりつ | ディスクの容量をどれだけ使ったかの割合です |
| p95 | ピーきゅうじゅうご | リクエストの 95% が、この時間以内に終わっています |
| p99 | ピーきゅうじゅうきゅう | リクエストの 99% が、この時間以内に終わっています |

稼働率とは、1 年のうちサービスが使えていた時間の割合です。年間の停止時間はあくまで概算です。実際は対象期間の数え方や、メンテナンスの扱い方で変わります。CPU 使用率やディスク使用率も、何 % から危険かは環境によって異なります。高い状態が続いていないかを見るのが基本です。p95 や p99 はパーセンタイルと呼びます。p99 なら、残りの 1% はこの時間より遅い、という意味になります。平均では見えない「一部の遅い利用者」を見つけるために使います。

## Mbps と MB のちがい

ネットワークの速さは bit、ファイルの大きさは byte で数えます。1 byte は 8 bit なので、同じ「メガ」でも 8 倍の差が出ます。100 Mbps の回線なら、計算上は 1 秒あたり約 12.5 MB です。ただし実際に出る速度は、環境によって異なります。

> **覚え方**: 小文字の b はビット、大文字の B はバイト。回線の速さは小文字の b、ファイルの大きさは大文字の B と覚えると取り違えません。
