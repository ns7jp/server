# サーバー基礎用語集（やさしい版）

[入口へ戻る](../../README.md) / [最初の実習](../beginner-learning-guide.md) / [リポジトリと結びつけて調べる](../server-building-keywords.md)

**この用語集のゴールは、現場で飛び交うサーバーの言葉を、自分の言葉で人に説明できるようになることです。**

13 章 408 語を、**一言 / たとえ / くわしく / 覚え方 / まちがえやすい / 関連語 / 確かめかた**の 7 項目で説明します。言葉から引きたいときは[用語さくいん](index.md)を開いてください。

想定している読者は、IT の経験が未経験から半年ほどで、これからサーバーの構築や運用の仕事に就く人です。頭から順に読んでも、分からない言葉が出たときに引いても構いません。目指すのは用語の丸暗記ではありません。「それは何ですか」と聞かれたときに、自分の言葉で 30 秒ほど話せる状態がゴールです。

## この用語集の使い方

各用語は、次の 7 つの項目で書かれています。最初から全部を読む必要はありません。

| 項目 | 何が書いてあるか | どう使うか |
| --- | --- | --- |
| 一言 | その言葉を 1 文で言い切った説明です | まずここだけ読んで全体をつかみます |
| たとえ | 身近なものに置きかえた説明です | 意味がぼんやりしたときに戻ります |
| くわしく | 仕組みや役割をもう少し掘り下げます | 一言では足りないと感じたら読みます |
| 覚え方 | 記憶に残しやすい手がかりです | 覚えにくい言葉だけ拾って使います |
| まちがえやすい | 似た言葉との違いや、よくある思いちがいです | 別の言葉と混ざったと感じたら読みます |
| 関連語 | いっしょに覚えると理解が進む言葉です | 1 つの言葉から周りへ広げるときに使います |
| 確かめかた | 状態を見るだけの安全な確認方法です | 実際に手を動かして確かめます |

読み方は 3 周に分けるのがおすすめです。

- 1 周目は、太字の見出しと「一言」だけを拾い読みします。分からない言葉は飛ばして構いません。
- 2 周目は、「たとえ」と「覚え方」を読みます。ここで言葉どうしのつながりが見えてきます。
- 3 周目は、「確かめかた」を自分の手で打ちます。画面に出た結果と説明を照らし合わせます。

## 安全に試すために

> 確認は、壊しても困らない検証用の環境で試してください。仕事で使っている本番の環境では試さないでください。
>
> `sudo` を付ける操作や、削除や停止を含む操作は、対象と元に戻す手順を先に確かめてから使ってください。
>
> この用語集に載せているのは、状態を表示するだけの確認方法です。設定を変える操作は載せていません。
>
> 実際に打っていない確認は「未実施」と分けて記録してください。読んだだけの内容を、試した内容として扱わないことが大切です。

## いちばん最初に覚える 15 語

| 言葉 | 一言でいうと | たとえるなら |
| --- | --- | --- |
| サーバー | 頼まれた仕事を引き受けて結果を返す側のコンピューターやソフトです | 注文を受けて料理を出す厨房 |
| クライアント | 仕事を頼む側のコンピューターやアプリです | 席に座って注文するお客さん |
| OS | 機械とアプリの間を取りもつ土台のソフトです | 店全体を回している店長 |
| Linux | サーバーで広く使われている OS の一種です | 業務用に作られた厨房設備 |
| プロセス | いま動いているプログラム 1 つ分のことです | いままさに調理中の 1 品 |
| サービス | 頼まれるのを待ちながら動き続けるプログラムです | 開店中ずっと待機している受付 |
| IP アドレス | ネットワーク上の住所を表す番号です | 建物の住所 |
| ポート | 同じ住所の中の、用件ごとの窓口番号です | 建物の中の部屋番号 |
| DNS | 名前を IP アドレスに変換してくれる仕組みです | 名前から番号を引く電話帳 |
| HTTP | Web のやり取りで使う会話の決まりごとです | 注文票の書き方のルール |
| TCP | 相手に届いたかを確かめながら送る通信のやり方です | 受け取りサインをもらう宅配便 |
| ファイアウォール | 通す通信と止める通信を分ける関所です | 建物の入口に立つ警備員 |
| バックアップ | もしものときに戻せるよう控えを取ることです | 大事な書類のコピー |
| 監視 | いつもと違う状態を早く見つける仕組みです | 毎日の体温測定と健康診断 |
| 冗長化 | 1 つ壊れても続くように予備を持たせることです | 車に積んである予備のタイヤ |

## 覚える順番（6 ステップ）

上から順に進めてください。前のステップの言葉が、次のステップの説明に出てきます。

| ステップ | 読む章 | 読み終えたら言えること |
| --- | --- | --- |
| ステップ 1（目安 40 分） | [1 章](01-server-client.md)・[2 章](02-hardware.md) | サーバーとクライアントの役割の違いと、サーバーが何でできているかを説明できます |
| ステップ 2（目安 45 分） | [3 章](03-os-process.md)・[4 章](04-linux.md) | OS の役割と、プロセスやファイル、ユーザーの基本的な考え方を説明できます |
| ステップ 3（目安 50 分） | [5 章](05-network-basics.md)・[6 章](06-network-protocols.md) | IP アドレスとポートと DNS を使って、通信が相手に届く道筋を説明できます |
| ステップ 4（目安 45 分） | [7 章](07-web.md)・[8 章](08-data-storage.md) | Web の要求が返るまでの流れと、データを保存して守る方法を説明できます |
| ステップ 5（目安 50 分） | [9 章](09-virtualization-cloud.md)・[10 章](10-availability.md) | 仮想化やクラウドの意味と、止まらない仕組みや遅くしない工夫を説明できます |
| ステップ 6（目安 60 分） | [11 章](11-security.md)・[12 章](12-operations.md)・[13 章](13-project.md) | 守り方と、運用中に何を見て何をするのかを、現場の言葉で説明できます |

6 ステップの目安時間を足すと、合計はおよそ 4 時間 50 分です。かかる時間は人によって異なります。1 日で詰め込まず、日をまたいで進めるほうが記憶に残ります。

## 7 日で 1 周する使い方

1 日 30 分から 60 分を目安にします。7 日目は読む章が多いので、足りなければ 2 日に分けても構いません。読んだ言葉は、その日のうちに一度声に出して説明してみてください。

| 日 | やること | 確認のしかた |
| --- | --- | --- |
| 1 日目 | 「いちばん最初に覚える 15 語」を一言だけ読みます | 15 語のうち 10 語を、表を見ずに一言で言えるか試します |
| 2 日目 | ステップ 1 を読み、1 日目の 15 語をもう一度試します | サーバーとクライアントの違いを、たとえを使って説明します |
| 3 日目 | ステップ 2 を読み、前日の内容を思い出します | プロセスとサービスの違いを、自分の言葉で言い直します |
| 4 日目 | ステップ 3 を読み、1 日目の 15 語を 3 日ぶりに試します | IP アドレスとポートと DNS の関係を、順番に説明します |
| 5 日目 | ステップ 4 を読み、検証環境で確かめかたを打ちます | ブラウザの要求が返るまでの流れを、順を追って話します |
| 6 日目 | ステップ 5 を読み、まだ言えない言葉を書き出します | 仮想化と冗長化を混ぜずに、それぞれ言い分けられるか試します |
| 7 日目 | ステップ 6 を読み、1 週間分を通しで振り返ります | 15 語すべてを、表を見ずに一言とたとえで説明します |

復習は間隔をあけると記憶に残ります。同じ言葉を、読んだ当日・翌日・3 日後・7 日後の 4 回、表を見ずに言えるか試してください。1 日目に読んだ 15 語なら、1 日目・2 日目・4 日目・8 日目にあたります。8 日目は次の周回の初日です。言えなかった言葉だけを、次の周回の重点にします。

## この用語集と、ほかの文書の使い分け

この用語集は、どのサーバーにも当てはまる**基礎の言葉**を、たとえと覚え方つきで説明します。特定の製品や、このリポジトリの実装には踏み込みません。

| 知りたいこと | 開く文書 |
| --- | --- |
| 言葉の意味を、たとえと覚え方つきで知りたい | この用語集（いまここ） |
| その言葉が、このリポジトリのどのファイルに現れるかを知りたい | [サーバー構築キーワード集](../server-building-keywords.md) |
| 手を動かして最初の実習を進めたい | [初心者向け学習ガイド](../beginner-learning-guide.md) |
| 次に学ぶ範囲を決めたい | [一本道ラーニングパス](../learning-path.md) |

用語の説明にある「たとえ」は、意味をつかむための入り口です。たとえをそのまま仕様として説明しないでください。実際の動きは、[確認コマンド逆引き表](commands.md)を使って自分の目で確かめます。
