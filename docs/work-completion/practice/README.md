# 自律的・利他的に、仕事を手放して進める

作成日：2026-09-06。AI作業での初回実践を記録し、読者が任意に使える短い手順をまとめた。本人の実施・感情の変化・他者への効果は未確認。

**自分で必要な一動作を選び、相手が使える形にして、完了した範囲を閉じる。気持ちが残っていてもよい。**

[初回の実施記録](first-run-2026-09-06.md)／[既存のサーバー運用キット](../README.md)

## 今日の1回

合図は **「終わったはずの作業を、もう一度開きたくなったとき」** とする。通常は1〜3分、短く済ませるなら最後の30秒版だけでよい。時間は試行用の目安で、効果の保証値ではない。

1. **必要な仕事を確かめる。** 安全・期限・約束・新しい不具合・未実施の必須確認があれば、必要な対応へ戻る。合格済みの同じ確認を繰り返したくなっただけなら次へ。
2. **誰に何を渡すかを1つ決める。** 例：「次に読む人が、実行場所と期待結果を迷わず選べる」。相手の反応を勝手に決めない。
3. **小さく1つ行う。** 必要なリンクを1つ示す、既存ログを指す、次の操作を1行残す。役立つものがすでにあれば、それを案内して終えてよい。
4. **追加案を分ける。** 今回の目的に必須でない改善は1行だけ採否待ちへ。必要な修正や約束は保留箱に逃がさない。
5. **閉じる。** 成果・未実施・再開条件を残し、別の仕事や休息へ移る。「もっと安心したか」「十分に善良だったか」を追加採点しない。

**30秒版：新しい事実はあるか → 必要な対応または1つの案内 → 再開条件を残して閉じる。**

## AI支援の作業で採用する規則

| 自律の規則 | 実際の動き |
|---|---|
| 依頼の目的を1つに定める | まず今回必要な成果を完成させる |
| 必要な調査・修正を自分で進める | 通常の判断を毎回ユーザーへ戻さない |
| 証拠がそろったら止める | 同じ結果の再取得やテストを理由なく繰り返さない |
| 範囲をむやみに増やさない | 任意の新機能・他リポジトリへの展開は採否待ちへ |
| 相手が再開できる情報を残す | 入口・根拠・未実施・次の条件を短く渡す |

自律性には、必要な権限や相手の意思を確認することも含む。主体的に仕事を進めることと、他者の判断を代行することを混同しない。規則を使うときは、対象の依頼・完了条件・権限を明確にする。この文書の閲覧だけで、AIの永続設定や定期実行が有効になることはない。

## 利他性の5条件

- **必要性**：相手の依頼や確認できた困りごとにつながっている。
- **選択権**：相手が使う・断る・後にすることを選べる。依頼のない連絡や介入を善意で正当化しない。
- **負担**：相手の読む量や作業量、自分の余力を考える。休息や必要な生活を犠牲にして埋め合わせない。
- **見返りからの独立**：感謝・承認・返事・評価を作業の完了条件にしない。
- **受け渡し**：成果の場所と限界を示す。渡したことと、相手が受領・理解・利用したことは別に記録する。

利他性の成果は、提供した情報だけでは証明できない。「負担を減らす意図で入口を整理した」と「実際に相手の負担が減った」は区別する。

## サーバー作業での選び方

| 起きたこと | 行動 |
|---|---|
| CIが成功したのに同じ画面を開き直す | 対象版と必要な検査結果を確認済みなら、証跡リンクを使って閉じる |
| もっと立派な構成を加えたくなる | 利用者の要件との関係を1行残し、任意案なら採否待ちへ |
| 自分だけで障害を解決したくなる | 影響・直前の変更・結果・次の仮説・必要支援を5行にする |
| 引継ぎ資料を際限なく増やす | 次の人が行う最初の操作と、成功・失敗の見分け方を優先する |
| 感謝されるまで追加の支援を続けたくなる | 約束した成果と受領状況を確認し、相手の選択に委ねる |

障害中の時間切れは、切り分けや連携を見直す合図。対応を放棄したり、引継ぎ受領前に担当を外れたりする理由にはしない。

## 次の実践

自然に合図が起きたときに、同じ手順を1回使う。日次の追加メニューや連続達成ノルマは作らない。記録は任意で、全場面合計1日1行まででよい。記録しない日や合図がなかった日は失敗に数えない。

```text
合図：＿＿ ／ 行った一動作：＿＿ ／ 次に再開する条件：＿＿
```

数回使ったら、「必要な仕事を守れたか」「自分や相手の負担が増えていないか」だけ振り返る。役に立たなければ手順を短くするか休む。手順自体を繰り返し確認するようになったら、カードを閉じて通常の仕事へ戻る。

危険や安全不明、強い苦痛がある場面では、この内面の整理より必要な安全確保や周囲の支援を優先する。断られた相手への別経路の連絡や、望まれていない支援を勧めるプログラムではない。

## 参考と限界

WHOは日常の短い練習を含むストレス対処のガイドを公開している。[Doing What Matters in Times of Stress](https://www.who.int/publications/i/item/9789240003927)。本書の自律・利他の5条件と仕事の終了手順は、この作業向けの運用案であり、WHOが本プログラムを評価・認定したものではない。

成功の記録は「実際に行った一動作」とする。感情の消失、人格の変化、本人の習得は、本人の報告なしに実施済みとしない。
