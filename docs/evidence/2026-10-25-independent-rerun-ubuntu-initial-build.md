# 独立再現記録（AI 不使用）：新しい VM での Ubuntu Server の初期構築

> **下書き（未実施 / NOT RUN）**：作業はまだ行っていません。実施日がファイル名の日付と違う場合は、
> `git mv` でファイル名を実施日に合わせます。記録を書き終えたら、この注記を消します。

- 進め方と守るルールは [独立再現の手引き](../independent-rerun-guide.md) の 4・5 節、様式は [テンプレート](templates/independent-rerun.md) です。
- **実施していない欄は空のまま残すか `NOT RUN` と書きます。** 推測値・概算値を入れないでください。
- 状態の語彙は既存の台帳と同じ **文書化済み／実装済み／実測済み／未実施（NOT RUN）** を使います。
