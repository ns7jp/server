## 確認結果

RS番号は本結果票専用。PASSは画像で確認できた観点に限定する。

| ID | 観点 | 判定 | 結果・証拠 |
| --- | --- | --- | --- |
| RS-01 | 不一致再確認 | PASS（想定不一致） | finalのみFAILED、他4件OK、before restore exit=1（E01） |
| RS-02 | 復元元の収録 | PASS | tar -tzfに対象finalを含む5ログとSHA一覧の6件（E01）。単独終了コード未採録 |
| RS-03 | 対象選別 | PASS | final候補1件のガードを通過し、RESTORE行に対象名を表示（E02） |
| RS-04 | 復元 | PASS | tar -xzfで試験先へ対象名1件を指定。後続検査へ進む（E02） |
| RS-05 | 復元後検査 | PASS | sha256sum -cで5件すべてOK、restore verify exit=0（E02） |

SHA一覧を作り直すコマンドは使わず、元の一覧で検査した。
set -eのサブシェルでtar成功後に照合・完了メッセージへ進んでいるが、tar単独の数値終了コードは未採録。
表示された全5件OKは一覧に対応するログ内容の一致を示し、権限やmtimeの一致までは示さない。
