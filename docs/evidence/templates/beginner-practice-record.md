# 初心者実習記録テンプレート

[学習ガイドへ戻る](../../beginner-learning-guide.md) / [全体の学習計画](../../learning-path.md)

この原本は未記入のまま残し、自分用にコピーして使います。期待値を実測欄へ転記しません。保存例は Git 対象外の `.artifacts/learning/first-practice.md` です。コピー後、このページの相対リンクを使う場合は元のテンプレートを開いてください。

最初は「1. 環境」と「2. 実行結果」の今回行う行だけを埋めれば十分です。**操作の前に結果を予想し、操作の直後に実際の出力を記録**します。説明と後日の再現は別に確認します。

## 1. 何をどこで行うか

| 項目 | 記録 |
| --- | --- |
| 日付・時刻・タイムゾーン | 【記入待ち】 |
| 実行者 | 【記入待ち】 |
| 実施の区分 | 個人学習 / CI / AI 支援環境から該当を記入 |
| OS・バージョン、VM / WSL2 等の区別 | 【記入待ち】 |

## 2. 実行結果

`PASS` は実行して期待値と一致、`FAIL` は実行して期待値と不一致、`BLOCKED` は不足条件により実行できず、`NOT RUN` は未実行です。画面を見たことと CLI で取得したことも分けます。

| 確認項目 | 期待値 | 実際のコマンド・時刻・結果・証跡の保存先 | 判定 |
| --- | --- | --- | --- |
| 前提診断 | `--minimal` の必須条件に FAIL なし、WARN の影響を確認 | 【記入待ち】 | NOT RUN |
| Python テスト | 終了コード 0、実際の件数を記録 | 【記入待ち】 | NOT RUN |
| 秘密値の追跡除外 | 4 パスが ignore、追跡ファイルなし | 【記入待ち】 | NOT RUN |
| 最小構成の起動 | app は Up / healthy、nginx は Up | 【記入待ち】 | NOT RUN |
| 入口経由の health | HTTP 200 | 【記入待ち】 | NOT RUN |
| 認証なしの画面 | HTTP 401 | 【記入待ち】 | NOT RUN |
| token なしの metrics | HTTP 401 | 【記入待ち】 | NOT RUN |
| 正しい認証付き API | HTTP 200 | 【記入待ち】 | NOT RUN |
| ブラウザ画面 | 認証後に数字が表示される | 【記入待ち】 | NOT RUN |
| nginx 計画停止 | nginx 停止、入口への接続失敗 | 【記入待ち】 | NOT RUN |
| nginx 手動再開 | health が HTTP 200 に戻る | 【記入待ち】 | NOT RUN |

## 3. 事実から考える

- 予想していたこと: 【記入待ち】
- 実際に観測したこと（出力や時刻）: 【記入待ち】
- その事実から立てた仮説: 【記入待ち】
- 仮説を確認するために行った操作: 【記入待ち】
- 分かった原因 / まだ分からないこと: 【記入待ち】
- 戻した操作と、元に戻ったことの確認: 【記入待ち】
- 次回はどう確認するか: 【記入待ち】

想定外のエラーがなければ「想定外のエラーなし」と書きます。FAIL の記録を作るために架空の障害や失敗を作りません。計画停止で予想どおり通信できなくなった場合は、停止確認という試験の PASS として、通信エラーの実出力を残します。

## 4. 自分の言葉で説明する

- **30 秒説明**: この個人ラボで、私は【環境】において【実施範囲】を行い、【期待値と実結果】を確認しました。【理由・学び】が分かりました。【未実施範囲】は未実施です。
- **構成の説明**: 利用者 → 【記入待ち】 → 【記入待ち】。各役割は【記入待ち】。
- **確認の説明**: health だけでは【記入待ち】まで確認できないため、別途【記入待ち】を調べました。
- **戻し方の説明**: 【記入待ち】。
- **AI・他者に支援された範囲**: 【記入待ち】。
- **自分でまだ説明できない点**: 【記入待ち】。

## 5. 習得の確認

読了・テスト成功だけで「習得済み」にしません。各行を確認した日と根拠を残します。案内を受けた場合は支援範囲を記入し、独力の結果として扱いません。

| 確認 | 判定条件 | 実施日・根拠・参照文書や受けた支援 | 判定 |
| --- | --- | --- | --- |
| 手順を使って実行 | 起動、4 件の HTTP 確認、停止・再開、終了の実結果がある | 【記入待ち】 | NOT RUN |
| 自分の言葉で説明 | 図と例文を閉じ、入口/app、200/401、戻し方、未実施を 30 秒で話せる | 【記入待ち】 | NOT RUN |
| 翌日の思い出し | 確認コマンドと期待値を先に書き、文書との違いを直せる | 【記入待ち】 | NOT RUN |
| 後日の再現 | 同じ専用環境で起動→4 件の HTTP 確認→終了を、対話的な案内なしで行い結果を比較できる | 【記入待ち】 | NOT RUN |

- 説明で詰まった点 / 次に練習する 1 点: 【記入待ち】
- 再現で自分が組み立てた手順と期待値（実行前に書く）: 【記入待ち】
- 参照した文書 / AI・他者から受けた案内: 【記入待ち】
- 初回と再現の結果の違い / 分かった理由: 【記入待ち】

文書を調べることは可能です。後日の再現は同じ環境・最小構成の確認であり、OS の新規構築・全監視の独力再構築を示しません。

公開前に秘密値、ユーザー情報、実 IP、画面内の個人情報を確認します。既存の CI・他者・AI 環境の実測を、自分の実行・業務経験・習得済みの結果へ置き換えません。
