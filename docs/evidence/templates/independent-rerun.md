# 独立再現記録（AI 不使用）テンプレート

このテンプレートは、**過去に一度実施した証跡を、AI アシスタントを使わずにもう一度なぞった記録**を残すための様式です。
新しい試験を増やすためのものではありません。「同じことを、自分の手と手順書だけでどこまでできるか」を
そのまま書き留めるためのものです。

- 使い方の考え方は [独立再現の手引き](../../independent-rerun-guide.md) を参照してください。
- 記入して完成した記録は `docs/evidence/` に `YYYY-MM-DD-independent-rerun-<対象>.md` として保存します。
- **実施していない欄は空のまま残すか `NOT RUN` と書きます。** 推測値・概算値を入れないでください。
- 状態の語彙は既存の台帳と同じ **文書化済み／実装済み／実測済み／未実施（NOT RUN）** を使います。

## 5. 手順書の不備（**この記録で一番価値のある欄**）

**ここが最重要です。** 手順書のとおりに打ったのに動かなかった箇所、書かれていない前提が必要だった箇所、
順番が逆だった箇所を書きます。AI に聞きながら進めると、その場で穴が埋められてしまい、
手順書の穴は表に出ません。AI を使わずになぞって初めて見つかる情報です。

| # | ファイルと箇所（行番号まで） | 手順書の記述 | 実際に起きたこと | 必要だった修正 | 修正の実施 |
| --- | --- | --- | --- | --- | --- |
| 1 |  |  |  |  | 未実施 / 実施済み（commit: ） |
| 2 |  |  |  |  | 未実施 / 実施済み（commit: ） |

> **手順書は実施中に直しません。** 直すのは記録を書き終えてからです。作業中に直してしまうと、
> 「手順書のとおりで動いたのか」が誰にも分からなくなります。
> この表に書き出したうえで、別のコミットとして修正してください。
