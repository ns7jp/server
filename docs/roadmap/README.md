# 将来構想（設計サンプル保管）

> **本ディレクトリの位置付け**
>
> 実装・実機検証がまだ無いテーマの設計サンプルを保管する。
> 未経験からの選考フェーズでは **実際に手を動かした部分（Docker Compose での基本監視、
> Molecule で検証済みの Ansible ロール、ネットワーク切り分けラボなど）を主軸に提示する**
> ため、AWS staging 環境や実運用データが前提の設計を本ディレクトリへ整理した。
> 設計を破棄したのではなく、環境や経験が揃った時点で一次導線へ戻す。

---

## 整理の判断理由

- ドキュメント一覧に実装済みのものと設計のみのものが同じ重みで並ぶと、区別がつきにくく、
  分量の多さが先に立って個々の完成度が伝わりにくい。
- ここに含めたテーマはいずれも AWS staging 環境や複数月分の運用データなど、
  現時点で用意できない前提を必要とする。今は「考えたこと」の証明にとどまる。
- この判断自体も [ns7jp/ns7jp の同様の整理](https://github.com/ns7jp/ns7jp/blob/main/docs/roadmap/README.md)
  と同じ考え方で記録し、経緯を辿れるようにする。
